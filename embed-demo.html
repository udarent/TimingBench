把 TimingBench 嵌进你的页面

默认只读，读者点一下波形就能直接改；改动会以事件回传给宿主。

① 一行 script + 一个 div

<script src="https://udarent.github.io/TimingBench/embed.js"></script>
<div data-timingbench data-height="240"
     data-wavejson='{ signal: [ { name:"clk", wave:"p....." } ] }'></div>

② 实际效果（可在页内直接编辑）

点击波形进入编辑；按 Esc 或点右下角的铅笔图标回到只读。

等待宿主事件…

③ 宿主不让跑脚本？只用一个 iframe

<iframe src="https://udarent.github.io/TimingBench/editor.html?embed=1#wj=<base64url(WaveJSON)>"
        width="100%" height="380"
        style="border:0;border-radius:10px;display:block"
        loading="lazy" title="Timing diagram"></iframe>

内容藏在 #wj= 后面的 base64url 里（不经过服务器、也不用转义），所以整段 HTML 是自包含的 —— 直接贴进 Obsidian 笔记这类只渲染 HTML、不执行 <script> 的地方即可。
代价：高度写死、没有 timingbench: 事件。在工作台点 <> 切到 iframe only 页签，它会按当前源码生成这段。Obsidian 里要作为原始 HTML 块贴，放进代码围栏只会显示成文本。

④ 想自己控制内容？用 JS

const api = TimingBenchEmbed.mount(document.querySelector('#myCard'), {
  wavejson: '{ signal: [...] }',
  mode: 'view'          // 或 'edit' 直接可编辑
});

document.querySelector('#myCard')
  .addEventListener('timingbench:change', e => {
    console.log('用户改了图，最新源码：', e.detail.wavejson);
  });
